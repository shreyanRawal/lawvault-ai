# LawVault — Your Legal Assistant

LawVault is a web application that makes everyday legal information more accessible in the
context of Nepali law. It brings together three tools behind a single, simple interface:

- **AI Legal Chatbot** — ask questions about the Nepali Civil Code and get answers that cite
  relevant sections, powered by a local language model.
- **Legal Calculators** — a suite of Nepal-specific legal and financial calculators.
- **Document Templates** — a library of downloadable legal document templates, plus a tool
  to generate/modify a document from your own uploaded file.

---

## Features

### 1. AI Legal Chatbot (`chatbot.html`)
A chat interface that answers questions about the Nepali Civil Code. Questions are sent to the
backend, which retrieves the most relevant sections of `civilcode.pdf` (using a FAISS vector
search) and asks a local **Llama 3.2** model to answer with citations.

### 2. Legal Calculators (`calculator.html`)
Nine client-side calculators (no server required):

- Court Fee Estimator
- Income Tax Calculator
- Vehicle Tax Estimator
- House Rent Tax Calculator
- Loan EMI Calculator
- Gratuity Calculator
- Land Registration & Capital Gain Tax Calculator
- Company Registration Fee Calculator
- Foreign Employment Compensation Calculator

### 3. Document Templates (`template.html`)
A searchable grid of ready-to-download legal templates (business contract, NDA, employment
contract, property lease, freelance contract, power of attorney, partnership agreement, loan
agreement, divorce agreement). It also includes a **Generate/Modify Document** tool: upload a
PDF/DOCX/TXT and describe a change, and the backend uses the local Llama 3.2 model to produce
a modified version.

---

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript (no framework, no build step). Icons via
  [Remix Icon](https://remixicon.com/) CDN.
- **Backend:** Python [Flask](https://flask.palletsprojects.com/) + Flask-CORS.
- **Language model:** [Ollama](https://ollama.com/) running **Llama 3.2** locally.
- **Retrieval:** [LangChain](https://www.langchain.com/) + [FAISS](https://faiss.ai/) over
  `civilcode.pdf`.

---

## Prerequisites

1. **Python 3.10+**
2. **[Ollama](https://ollama.com/)** installed and running locally, with the model pulled:
   ```bash
   ollama pull llama3.2
   ```
   > Ollama is only needed for the chatbot and the document generator. The calculators and
   > template downloads work entirely in the browser without it.

## Setup

```bash
# from inside the lawvault/ folder

# 1. Create and activate a virtual environment
python -m venv venv
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

# 2. Install dependencies
pip install -r requirements.txt
```

---

## Running the App

1. Make sure Ollama is running (`ollama serve` if it isn't already) and `llama3.2` is pulled.
2. Start the backend:
   ```bash
   python app.py
   ```
   The server runs at `http://localhost:5000`.
   > **First run:** the app builds a FAISS index from `civilcode.pdf`. This happens once and
   > can take a few minutes. Later runs load the saved index and start quickly.
3. Open **`home.html`** in your browser to use the app.

| Feature | Needs `app.py` running? |
| --- | --- |
| Legal Calculators | No |
| Template downloads & search | No |
| AI Chatbot | Yes |
| Generate/Modify Document | Yes |
